# Carpeta art/ (recursos importables)

El juego busca aquí archivos opcionales. Si un archivo NO existe, usa el dibujo hecho por código, así que puedes ir añadiéndolos de a uno.
Después de copiar archivos, abre el proyecto en el editor de Godot para que los importe (la primera vez).

- art/3d/    modelos .glb  -> ver ART_GUIDE.md (nombres exactos)
- art/icons/ iconos .png   -> ver ART_GUIDE.md (nombres exactos)
