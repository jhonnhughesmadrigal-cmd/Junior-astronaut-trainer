# Misión Perseo — Junior Astronaut Mission Trainer

Juego Godot 4.x (probado con 4.4.1; desde v39 también con 4.7.2) para niños de 7 a 12 años, en español e inglés. Arte y audio generados por código.
Más detalle de mecánicas y datos en `DATOS.md`.

Exportar web: `godot --headless --path . --export-release Web web/index.html`
